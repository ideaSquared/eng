# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
<https://github.com/ideaSquared/eng/security/advisories/new>

Do not open a public issue or pull request for a vulnerability, and do not include secrets or tokens in a report.

## What to expect

- We acknowledge a report within 3 working days.
- We assess it and tell you whether we treat it as a vulnerability, usually within 10 working days.
- We fix confirmed issues as soon as we can and credit you in the advisory if you want that.

## Scope

The `eng` CLI, `install.sh` and `install.ps1` in this repository.
